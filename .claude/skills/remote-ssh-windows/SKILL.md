# Windows ↔ 远程 Linux

## 前提：本地能 SSH 连上远程

这个 skill 的一切都建立在 SSH 通路上。如果还没配好，先读 [operations.md](operations.md)：
- 密钥配对（"第一步"）
- 中文 Windows 用户名导致 ssh 报错（"Git Bash 额外坑"）

## 两条独立路径

| 你要做什么 | 信号 | 去哪 |
|-----------|------|------|
| **远程执行命令**（一次性） | "看一下"、"执行"、"跑一下"、"cat"、"pipe 到容器"、"传脚本"、"杀进程"、"后台启动"、"github 被墙" | → [operations.md](operations.md) |
| **项目同步**（持续开发） | "本地没环境"、"Claude 看服务器文件"、"实时同步"、"Syncthing"、"本地改代码怎么到服务器" | → [project-sync.md](project-sync.md) **先读顶部「Claude 行为约束」** |

两条路互不依赖。

## 同步模式下的关键约束

项目同步配好后，**需要远程执行的脚本直接写到项目目录**（而不是 `/tmp/`、`/c/sshkeys/` 等临时路径）。写完后等 ~10s（文件 watcher 延迟），服务器就能看到。直接 `ssh ... 'bash /path/to/script.sh'` 执行，不需要 pipe。
